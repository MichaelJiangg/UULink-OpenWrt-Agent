# UULink OpenWrt agent

- Keep this repository limited to the UULink router agent, its release builder, tests, and documentation. Do not import iOS application code, local credentials, or wlmb-server source.
- The validated target is U30 Air OpenWrt with `mu300dash`, `ubus`, `rpcd-mod-ucode`, and `ucode`. The installer checks these services; it does not enforce a hardware model name.
- `files/` mirrors destination paths on the router. `install.sh` handles a new installation; `upgrade.sh` accepts only explicitly recognized earlier UULink files, including the published `v0.1.0-rc.1` data agent. The versioned `setup.sh` generated by `build-release.py` is the public entry point.
- Keep the plugin read-only. It uses the existing `/ubus/` endpoint and stores only sanitized snapshots under `/tmp/uulink/`. Identity and client details are read on demand and never cached.
- Build release assets only under ignored `.build/`. Include only the allowlisted files and the MIT license. Update checksums and the published copy command for every changed release asset.
- Before a release, run `python3 -m unittest discover -s tests -p test_release.py -v`, `sh -n install.sh upgrade.sh release-setup.template.sh`, and verify the generated `SHA256SUMS`. Validate installation or upgrade, including the LuCI menu and four read-only pages, on the target router before marking it complete.
- Record actual progress and validation in `ROADMAP.md`. Do not record untested device behavior as complete.
